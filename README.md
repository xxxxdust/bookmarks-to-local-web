# 收藏变本地知识库

把收藏的帖子、文章和阅读笔记，整理成可以搜索、分类阅读、复制提示词的本地网页。

**这是一个供 AI 助手使用的 Skill，目前处于需求验证阶段。** 它不只是导出链接：助手需要实际读取资料，再整理每篇重点、方法、提示词和可获得的原始资源。

## 适合谁

收藏了很多资料，但想用时找不到重点；或者经常收藏 AI 提示词、Skill 和教程，希望把内容保存在自己的电脑上。

## v0.2：可以持续更新

- 同一批重复执行不重复添加；新增内容合并到同一个收藏库。
- 固定阅读入口，成功生成后才切换新版；旧版本保留，可回退。
- 保留个人笔记；新批次没出现的旧收藏不会被删除。
- 可以配合宿主的定时任务运行。**下载 Skill 不会自动启用日程**，需要告知助手检查时间、时区、账号和知识库路径。登录/浏览器不可用时仍可能需要人工处理。

例如对助手说：“把这个收藏库设为每天上午9点、北京时间增量更新，有新增或新问题才告诉我。”

[持续更新操作说明](references/incremental-sync.md) · 当前同步器支持 macOS/Linux，Windows 尚未验证。

## 会得到什么

- 逐篇重点：观点、方法、使用建议、来源和读取状态。
- 提示词手册：区分作者原版、整理改写版和用户原稿。
- 公开资源归档：有权限保存的 Skill、模板及相关文件。
- 本地网页：搜索、分类、提示词复制、原文件阅读。
- Markdown 和 JSON：便于继续编辑、迁移和备份。

## 怎么试用

需要一个能读取 Skill、使用浏览器或读取文件的 AI 助手，以及 Python 3.9 或以上。

1. 下载上面的 Skill ZIP，解压得到 `bookmarks-to-local-web` 文件夹。
2. Codex 用户将该文件夹放到个人技能目录 `~/.codex/skills/`，不要覆盖已有同名版本。也可以把文件夹交给助手，明确要求读取其中 `SKILL.md` 并按其执行。
3. **第一次先拿5—10条资料试用。** 提供收藏链接、导出的笔记文件，或允许助手读取已登录浏览器里的收藏页面。
4. 向助手发送：

```text
使用 $bookmarks-to-local-web，先把我提供的这5—10条收藏整理成本地知识库。
请逐篇读取并总结重点，整理可复用的提示词和公开资源，生成可搜索的本地阅读网页。
说明实际读到了哪些内容；读不到的正文、视频或附件请标记，不要补编。
```

Python 脚本只负责将整理好的数据排成网页，不会自己登录、抓取、理解或总结文章。

### 不连接账号也能看示例

在仓库目录运行：

```bash
python3 scripts/build_library.py --input examples/library.json --output demo-output
python3 -m http.server 8767 --bind 127.0.0.1 --directory demo-output
```

然后在浏览器打开 `http://127.0.0.1:8767/阅读页.html`。端口被占用时换一个；生成器不会覆盖已有输出目录。该示例完全虚构，既不包含任何人的收藏，也不代表抓取能力。

### 持续更新示例

```bash
python3 scripts/sync_library.py --input examples/library.json --library my-library
python3 -m http.server 8767 --bind 127.0.0.1 --directory my-library
```

后续仍用同一个 `my-library` 目录，输入新批次 JSON；固定入口为 `http://127.0.0.1:8767/阅读页.html`。再次运行同一示例会报告没有变化。第一次请使用新的空目录，保留旧版输出。

## 目前验证到哪里

已用一批45篇已有笔记、62条提示词验证生成器，以及搜索、分类、复制、原文件预览和窄屏阅读。资源预览另用测试文件验证。已检查重复编号、失效引用、越界路径、非法链接和覆盖已有输出的拒绝行为。

v0.2 增加12项自动检查，覆盖重复运行、增量ID重映射、URL别名、笔记保留、完整度保护、失败保留旧版、回退、资源内容变化、空批次不删除、并发拒绝和旧目录保护。可运行 `python3 -m unittest discover -s tests -q` 复验。

**尚未验证所有平台。** 能否读取取决于登录权限、平台限制和助手可用的工具。视频缺少字幕、正文受权限限制、作者没有公开文件时，会明确列出缺失。它不是全平台一键爬虫，不会绕过访问限制，也不会安装或运行收藏里的第三方 Skill。

本地服务停止后网页地址会失效，保存在电脑里的 HTML、Markdown 和资源文件仍保留。生成结果不自动发布到公网；所用 AI 助手和模型仍可能处理输入内容，不能把“保存到本地”等同于“完全离线处理”。
